# nome-em-elementos-quimicos
🧪 Nome em Elementos Químicos (Name in Elements)
Uma aplicação web interativa que converte qualquer nome ou texto em uma sequência composta pelos símbolos dos elementos da Tabela Periódica, no estilo clássico de elementos químicos.

📌 Sobre o Projeto
O Nome em Elementos Químicos analisa uma string digitada pelo usuário e busca combinações de letras que correspondam aos símbolos dos 118 elementos químicos conhecidos. Caso uma letra ou combinação não corresponda a nenhum elemento químico real, a aplicação exibe a letra em um formato estilizado compatível para manter a consistência visual.

🎯 Principais Funcionalidades
Mapeamento Inteligente: Algoritmo de busca que prioriza combinações de 2 letras antes de buscar elementos de 1 letra para maximizar os correspondentes químicos.

Visual Estilizado: Exibição no formato de cartões da tabela periódica (Símbolo, Nome do Elemento, Número Atômico e Massa Atômica).

Feedback Visual: Destaque para os elementos encontrados vs. caracteres não mapeados.

Interface Responsiva: Adaptada para telas de celulares, tablets e computadores.
